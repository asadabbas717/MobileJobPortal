# MobileJobPortal

An Expo / React Native starter repository. The current App.js renders the default starter screen; job listings, search, applications and backend integration are not implemented.

## Run the starter

Install Node.js and npm, then run from the repository root:

```bash
npm install
npm start
```

The manifest uses Expo SDK 54, React 19.1 and React Native 0.81.5. Use an Android emulator or compatible Expo Go device. Runtime/device validation was not performed during this documentation review.

## Status

Learning scaffold, not a completed job portal. There is no root license granting reuse terms. This repository is not recommended as a professional profile pin.
